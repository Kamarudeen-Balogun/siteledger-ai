# Product steering

Read `PROJECT_BRIEF.md` before each task and follow section 16 in order.

SiteLedger turns a foreman's voice note and photos into a human-confirmed, costed daily site record in naira against a BoQ. Money, photographic proof, and fit for Nigerian sites define the product.

The foreman uses Telegram or a mobile web page. The PM or QS reviews the record; the client reads the PDF without logging in. One fictional demo company and project are enough.

Build no item on section 5's cut list. Never invent quantities, rates, users, revenue, or Kiro build evidence. Ask the builder about ambiguous tasks.
